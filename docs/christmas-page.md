# Christmas offer page

The public `/kaledos/` page is generated by the normal Jekyll build. The home seasonal promotion and the first program card link to it. The existing kindergarten offer remains at `/programos/kaledos-darzeliams/`.

The layout reuses the existing navigation, contact footer, consent services and Amatic SC / KG Kindergarden fonts. Page styles and interactions are scoped to `.christmas-hub`. User-supplied photos are in `img/kaledos`.

The inquiry form uses the site's existing FormSubmit AJAX endpoint and shared `js/corporate-inquiry-form.js`. Name and email are required; planning details are optional. Failed requests retain all entered values. The form resets and emits `christmas_inquiry_form_submit` only after explicit server acceptance. Tests must intercept submission requests so no test emails are sent. Messenger uses the existing site contact URL.

For a local preview with analytics disabled:

```powershell
bundle exec jekyll serve --config _config.yml,_config.christmas-preview.yml --host 127.0.0.1 --port 4173
```

Only one preview server should run for this checkout. An older watcher can overwrite output using stale configuration.
